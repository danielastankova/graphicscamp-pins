GraphicsCamp Privacy Policy

How the GraphicsCamp Pinterest app handles data

Last updated: 26 November 2026

About this app

GraphicsCamp (“the app”) is a private, single-user tool operated by GraphicsCamp, a small Etsy shop based in Sofia, Bulgaria, that sells printable routines, chore charts and calm-down tools for children (etsy.com/shop/GraphicsCamp).

The app publishes GraphicsCamp’s own product pins to GraphicsCamp’s own Pinterest business account on a weekly schedule. It is not offered to other Pinterest users or to the public.

What Pinterest data the app accesses

The app uses Pinterest’s official OAuth authorization and requests only these scopes: user_accounts:read, boards:read, pins:read and pins:write. It uses them to:

  • read basic information about the connected GraphicsCamp account (username and account type) to confirm the right account is connected;
  • read the account’s own boards (names and IDs) so each pin is placed on the correct board;
  • create pins and record each created pin’s ID so the same pin is never published twice.

The app does not read, collect or store data about other Pinterest users, followers, audiences or analytics.

How data is used and stored

  • Authentication uses Pinterest OAuth only. The app never asks for or stores Pinterest passwords or session cookies.
  • OAuth access and refresh tokens are stored only on the shop owner’s own computer or as encrypted GitHub Actions secrets, and are used only to call the Pinterest API on behalf of the GraphicsCamp account.
  • A small log of created pin IDs is kept to prevent duplicate posts.
  • The app does not scrape Pinterest.
  • No Pinterest data is sold, shared with third parties, or used for advertising or profiling.

Retention and deletion

Tokens are deleted when access is revoked. The account owner can revoke the app’s access at any time in Pinterest’s account settings. Logs of created pin IDs are deleted after 90 days.

Changes to this policy

If the app’s use of Pinterest data changes, this page will be updated and the date above will change.
